# Streamlit — Dashboard operacional

Demonstra um dashboard rápido em Python para um Gêmeo Digital de edifício inteligente.

## Mostra

- KPIs de estado atual;
- filtros por ambiente;
- série temporal por métrica;
- tabela de estado dos sensores;
- alertas e recomendações simples.

## Execução

Pelo projeto principal:

```bash
docker compose up --build streamlit
```

Acesse: <http://localhost:8501>
