# p5.js — Simulação visual 2D

Demonstra uma planta baixa simplificada com comportamento dinâmico.

## Demonstra

- canvas 2D;
- animação de pessoas/partículas;
- zonas com cores semânticas;
- painel lateral da sala selecionada;
- modos de interação: pessoas, ventilar e falha térmica;
- botão de reset;
- layout responsivo sem painel lateral competindo com o canvas;
- indicadores separados de temperatura e CO₂;
- áreas dos ambientes em metros quadrados;
- cartões de resumo dos ambientes acima do canvas;
- canvas mais limpo, mantendo apenas rótulos simples dentro da planta;
- relação entre ocupação, CO₂, temperatura e status operacional.

## Uso em aula

Mostre que nem toda interface de Gêmeo Digital precisa ser gráfico tradicional. Uma planta 2D pode comunicar estado, posição e dinâmica.

## Execução

```bash
docker compose up web
```

Acesse: <http://localhost:8080/p5/>
