# 8thWall/WebAR — Mock de inspeção

Esta demo é um **mock conceitual** executável no navegador, usando A-Frame.

## Por que mock?

O 8thWall normalmente exige conta e publicação em sua plataforma. Para a aula, este exemplo permite demonstrar a ideia de AR sem depender de login.

## Demonstra

- ativo físico representado em 3D;
- painel flutuante de dados operacionais;
- cor de alerta;
- uso de AR como interface de campo.

## Execução

```bash
docker compose up web
```

Acesse: <http://localhost:8080/8thwall-mock/>
