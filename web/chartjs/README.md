# Chart.js — Painel de sensores

Mostra como criar gráficos web rapidamente em uma página HTML.

## Demonstra

- gráfico de linha para tendência temporal;
- gráfico de barras para comparação entre ambientes;
- gráfico de rosca para distribuição de estados;
- cores semânticas: normal, atenção e crítico.

## Execução

```bash
docker compose up web
```

Acesse: <http://localhost:8080/chartjs/>
