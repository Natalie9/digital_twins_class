D3.js — Fluxo de Decisão do Gêmeo Digital

Esta visualização mostra a cadeia de decisão: ambiente físico → sensor → gateway → modelo → alerta → operador. Clique em uma sala para destacar seu fluxo.

  • As cores indicam o estado atual: normal, atenção ou crítico.
  • A espessura/destaque mostra o caminho do ambiente selecionado.
  • O objetivo é explicar a arquitetura informacional, não apenas valores isolados.
