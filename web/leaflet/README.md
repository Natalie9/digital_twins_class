# Leaflet — Mapa operacional do Gêmeo Digital

Demonstra dados espaciais em um Gêmeo Digital.

## Demonstra

- mapa interativo com basemaps;
- marcadores por sensor;
- rótulos espaciais;
- popups com métricas;
- camadas ligáveis/desligáveis;
- área monitorada do campus;
- zonas de atenção/críticas;
- filtros por estado;
- painel lateral com KPIs e sensor selecionado;
- lista de prioridade de inspeção;
- rota sugerida da base de manutenção até o sensor selecionado.

## Uso em aula

Use para discutir quando mapa é melhor que dashboard: ativos distribuídos, campus, cidades inteligentes, rotas, localização de falhas e priorização de inspeção em campo.

## Execução

```bash
docker compose up web
```

Acesse: <http://localhost:8080/leaflet/>
