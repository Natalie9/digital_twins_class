# Leaflet — Mapa de sensores

Demonstra dados espaciais em um Gêmeo Digital.

## Demonstra

- mapa interativo;
- marcadores por sensor;
- popups com métricas;
- camadas ligáveis/desligáveis;
- zonas de atenção/críticas.

## Uso em aula

Use para discutir quando mapa é melhor que dashboard: ativos distribuídos, campus, cidades inteligentes, rotas e localização de falhas.

## Execução

```bash
docker compose up web
```

Acesse: <http://localhost:8080/leaflet/>
