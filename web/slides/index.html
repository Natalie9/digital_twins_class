Chart.js

Biblioteca JavaScript para criar gráficos responsivos em páginas web com pouca configuração.

O que é

Chart.js entrega componentes prontos para gráficos comuns: linha, barra, rosca, radar, dispersão e área.

É indicada quando a aplicação web precisa incorporar visualizações tradicionais de forma rápida e leve.

Quando usar em Gêmeos Digitais

  • séries temporais de sensores;
  • comparação entre ativos ou ambientes;
  • distribuição de estados;
  • painéis web simples integrados a Flask, Node, Django etc.

Streamlit

Framework Python para transformar scripts de análise de dados em aplicações web interativas.

O que é

Streamlit permite criar interfaces com poucas linhas de Python: métricas, filtros, tabelas, gráficos, upload de arquivos e layout em colunas.

É muito usado para prototipação, ciência de dados, ML e dashboards internos.

Quando usar em Gêmeos Digitais

  • prototipar dashboard operacional rapidamente;
  • explorar dados de sensores e modelos preditivos;
  • criar interfaces para especialistas técnicos;
  • validar KPIs antes de desenvolver produto final.

D3.js

Biblioteca JavaScript para visualização de dados customizada, baseada em SVG, Canvas e DOM.

O que é

D3 não é apenas uma biblioteca de gráficos prontos. Ela oferece primitivas para mapear dados em elementos visuais.

É ideal quando a forma da visualização precisa ser desenhada conforme o problema.

Quando usar em Gêmeos Digitais

  • grafos de sensores, ativos e dependências;
  • fluxos de energia, processo ou informação;
  • diagramas interativos e drill-down;
  • visualizações que não cabem em gráfico padrão.

p5.js

Biblioteca JavaScript criativa para desenho, animação, interação e simulações em Canvas.

O que é

p5.js foi criada para tornar programação visual acessível. Ela facilita desenhar formas, animar partículas, capturar interação e simular comportamentos simples.

É muito útil para protótipos visuais e experiências didáticas.

Quando usar em Gêmeos Digitais

  • planta baixa interativa;
  • simulação de fluxo de pessoas, ar, calor ou partículas;
  • representação visual de zonas afetadas;
  • interfaces experimentais e educacionais.

Leaflet

Biblioteca JavaScript leve para mapas interativos, marcadores, camadas e popups.

O que é

Leaflet é uma das bibliotecas mais populares para mapas web 2D. Integra mapas base, marcadores, polígonos, círculos, popups e plugins.

É simples, extensível e funciona bem em desktop e mobile.

Quando usar em Gêmeos Digitais

  • sensores distribuídos em campus ou cidade;
  • ativos em campo e inspeções;
  • zonas de risco, rotas e áreas afetadas;
  • interfaces de operação geográfica.

8th Wall / WebAR

Stack para criar experiências AR e 3D no navegador, agora com componentes abertos em 8thwall.org.

O que é

8th Wall permite experiências WebAR sem instalar aplicativo nativo. A versão atual combina Studio Desktop, exemplos no GitHub e engine distribuída.

O projeto passou a ser aberto; o SLAM continua distribuído como binário.

Quando usar em Gêmeos Digitais

  • inspeção de ativo em campo;
  • overlay de status, risco e instruções;
  • manutenção assistida;
  • treinamento operacional no ambiente físico.

Pergunta-chave

Qual decisão o usuário precisa tomar olhando para a interface?

Boas práticas

Interface deve reduzir incerteza

Princípios úteis

  • visão geral primeiro;
  • zoom/filtro quando necessário;
  • detalhes sob demanda;
  • cores com significado operacional;
  • alerta sempre ligado a ação sugerida.

Evitar

  • excesso de gráficos sem decisão associada;
  • cor decorativa confundida com status;
  • AR/3D usado só por impacto visual;
  • ocultar incerteza, latência ou qualidade do dado.
Atividade final

Projete a interface do seu Gêmeo Digital

  • Quais dados precisam aparecer?
  • Quais KPIs indicam risco?
  • Precisa de dashboard, mapa, 2D, 3D ou AR?
  • Onde entram alertas e recomendações?
  • Uma interface imersiva agrega valor ou é excesso?
